# Distribution-Analysis
 
## AI & ML Internship – Veda Technology

### Project Description
This project focuses on creating a histogram for a numerical variable and analyzing the distribution of its values using Python.

### Objective
To understand how numerical data is distributed by analyzing its frequency, concentration, spread, and skewness.

### Tools and Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

### Dataset
Iris Dataset

Selected Numerical Variable:
- Sepal Length

### Project Steps
1. Import required libraries.
2. Load the Iris dataset.
3. Explore the dataset.
4. Select a numerical variable.
5. Calculate mean, median, and standard deviation.
6. Create a histogram using Matplotlib.
7. ### Histogram
A histogram is used to represent the frequency distribution of numerical data.

### Observations
1. The histogram shows the distribution of sepal length values.
2. The bars represent the frequency of different sepal length ranges.
3. Mean, median, and skewness help understand the distribution.

### Conclusion
This project helped me understand numerical data distribution using histograms. I learned how to use Python, Pandas, and Matplotlib for data analysis and visualization.
